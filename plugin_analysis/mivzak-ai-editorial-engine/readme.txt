תוסף פנימי לחדשות מבזק לייב ליצירת כתבות אוטומטית לפי קטגוריות, עם מחקר רשת, כתיבה עיתונאית, תמונה ראשית ובקרת איכות.

== התקנה ==
1. העלו את קובץ ה-ZIP דרך תוספים > תוסף חדש > העלאת תוסף.
2. הפעילו את התוסף.
3. היכנסו ל"מנוע כתבות AI" בלוח הבקרה.
4. הגדירו OpenAI API Key במסך ההגדרות.
5. עברו למסך הקטגוריות, ודאו שכל פרופיל ממופה לקטגוריית וורדפרס קיימת.
6. התחילו ביצירה ידנית, ורק לאחר בדיקות הפעילו אוטומציה.


== שינויים ב-1.0.1 ==
* נוספו שני כפתורי יצירה ידנית: שמירה כטיוטה או פרסום מיידי.
* ברירת המחדל נשארת טיוטה בפרופילים המובנים.
* פורסם תיקון פנימי קטן בלוגיקת עצירת כפילויות.


== שינויים ב-1.0.2 ==
* שדות חלון זמן לחיפוש ומרווח בין יצירות הוחלפו לבחירה נוחה מתוך אפשרויות.
* נוספה אפשרות אוטומציה צפופה יותר: כל 5 או 10 דקות.
* טבלת הפרופילים מציגה זמנים בצורה קריאה יותר.
* תוקן סף המינימום הפנימי למרווח יצירה מ-15 ל-5 דקות.
* מנגנון הבדיקה האוטומטי רץ כעת כל 5 דקות כדי לתמוך גם בפרופילים של 5 ו-10 דקות.


== שינויים ב-1.0.3 ==
* מסכי בחירה חזותיים למודלי טקסט, בקרת איכות, בדיקת תמונה ויצירת תמונה, כולל המלצה מודגשת ועלויות מוצגות.
* נוספה אפשרות חריגה לכל פרופיל: מודל טקסט, מודל QA, מודל ראייה, מודל תמונה, גודל ואיכות תמונה.
* נוספה שליטה פר-פרופיל בחיפוש רשת: ירושה מהגדרה כללית, הפעלה או כיבוי לחיסכון בעלויות.
* ברירת המחדל לתמונה שודרגה ל-GPT Image 2 בגודל 1280×720, מותאם ל-Discover ול-News.
* נוסף חיווי בולט על כל כתבה שנוצרה דרך התוסף, גם ברשימת הפוסטים וגם במסך העריכה.
* נוסף עמוד סטטיסטיקות צפייה עצמאי עם סינון לפי קטגוריה ותאריכי פרסום.
* נוסף מנגנון מדידת צפיות עצמאי של התוסף, שאינו נשען על מונה צפיות של וורדפרס.

= 1.0.6 =
* מד התקדמות חי ותצוגת שלבים בזמן יצירה ידנית.
* סינון פרופילים לפי תדירות, סטטוס פעילות, סטטוס פוסט וחיפוש חופשי.
